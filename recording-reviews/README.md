# Human-recording approvals

Keep review JSON here, outside the public asset directory. Do not include performer contact information or private contracts. See [the production guide](../docs/audio-production.md) for the schema and approval process. A checked box is a production assertion, not an automatic detector of human speech or accent quality.

Example location: `recording-reviews/vi-south/linh/hello.json`, paired with `public/audio/dialogue/vi-south/linh/hello.mp3`. Neither file alone activates a recording. The generated client registry contains only paths, caption text and audio hashes.
